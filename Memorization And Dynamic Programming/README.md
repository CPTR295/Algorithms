# Memoization and Dynamic Programming

This folder contains implementations of various algorithms using **memoization** and **dynamic programming** techniques.

## Problems

### 1. Burger Fervor

Homer Simpson has **t minutes** to spend eating **burgers** and drinking **beer**. There are **two types of burgers**: one taking **m minutes**, the other **n minutes**. He wants to spend **as much time as possible eating burgers**, using any remaining time for beer.

- [BurgerFervor_UsingMemorization.md](BurgerFervor_UsingMemorization.md)
- [BurgerFervor_UsingDynamicProgramming.md](BurgerFervor_UsingDynamicProgramming.md)

### 2. Hockey Rivalry

Two hockey teams (**Geese** and **Hawks**) each played **n games**. For each game, we know the result (**Win** or **Loss**) and goals scored. We don't know which games were against each other. A **rivalry game** is valid when one team wins with more goals than the other team loses with. The task is to find the **maximum number of goals** scored in possible rivalry games.

- [HockeyRivalry_UsingMemoization.md](HockeyRivalry_UsingMemoization.md)
- [HockeyRivalry_UsingDynamicProgramming.md](HockeyRivalry_UsingDynamicProgramming.md)

### 3. Money Grubbers

You want to **buy apples (or items) as cheaply as possible**. The store offers a **unit price** for a single item and **m pricing schemes** for bulk purchases. Each scheme gives **n items for price p**. The goal is to buy **at least k items** while spending **minimum money**.

- [MoneyGrubbers_UsingMemoization.md](MoneyGrubbers_UsingMemoization.md)
