# Graphs Algorithms

This folder contains implementations of graph algorithms, including Breadth-First Search (BFS) and Dijkstra's algorithm solutions to various algorithmic problems. Each problem includes both a C language implementation and a detailed markdown explanation.

## Problems

### 1. Book Translation Using BFS
- **File**: `BookTranslation_UsingBFS.c` / `BookTranslation_UsingBFS.md`
- **Description**: Solves the language translation cost problem where you need to find the minimum total cost to translate English into multiple target languages using available translators.

### 2. Knight Chase Using BFS
- **File**: `KinghtChase_UsingBFS.c` / `KinghtChase_UsingBFS.md`
- **Description**: Simulates a board game between a pawn and a knight, determining the best outcome for the knight (win, stalemate, or loss) and the minimum number of moves required.

### 3. Rope Climb Using BFS
- **File**: `RopeClimb_UsingBFS.c` / `RopeClimb_UsingBFS.md`
- **Description**: Bob needs to climb an infinitely long rope to reach at least height `h` meters, avoiding itching powder segments, using jumps of exactly `j` meters and falls to any valid height.

### 4. Grandma Planner Using Dijkstra
- **File**: `GrandmaPlanner_UsingDijkstra.c` / `GrandmaPlanner_UsingDijkstra.md`
- **Description**: Helps grandma plan her route to visit multiple locations with minimum total travel time, considering different transportation modes and their costs.

### 5. Mice Maze Using Dijkstra
- **File**: `MiceMaze_UsingDijkstra.c` / `MiceMaze_UsingDijkstra.md`
- **Description**: Finds the shortest path for mice to escape a maze with weighted edges, using Dijkstra's algorithm to minimize the total path cost.
