# Algorithms

A comprehensive collection of algorithm implementations across various topics and techniques.

## Folders

### [Binary Search](Binary%20Search/)
Efficient searching and optimization using binary search on monotonic sequences.

Problems included:
- Feeding Ants
- River Jump
- Living Quality

### [Graphs](Graphs/)
Graph algorithms and problems solved using Breadth-First Search (BFS) and Dijkstra's algorithm.

Problems included:
- Book Translation
- Knight Chase
- Rope Climb
- Grandma Planner
- Mice Maze

### [Hash Table](Hash%20Table/)
Algorithms and data structures related to hash tables and hashing techniques.

Problems included:
- Compound Words
- Spell Check
- Unique Snowflakes

### [Heaps And Segment Trees](Heaps%20And%20Segment%20Trees/)
Data structures for efficient range queries and priority management using heaps and segment trees.

Problems included:
- Building a Treap (Recursion)
- Building a Treap (Segment Tree)
- Supermarket Promotion
- Maximum Pair Sum with Updates

### [Trees and Recursion](Trees%20And%20Recursion/)
Implementations using recursive approaches and tree-based algorithms.

Problems included:
- Burger Fervor
- Descendant Distance
- Halloween Haul
- Money Grubbers
- Hockey Rivalry

### [Memoization and Dynamic Programming](Memorization%20And%20Dynamic%20Programming/)
Algorithms optimized using memoization and dynamic programming techniques.

Problems included:
- Burger Fervor
- Hockey Rivalry
- Money Grubbers

## Getting Started

Each folder contains:
- **C source files** - Implementation code
- **Markdown documentation** - Problem statements and explanations
- **README.md** - Folder-specific overview with problem links
